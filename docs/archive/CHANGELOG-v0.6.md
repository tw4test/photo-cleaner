## 評估狀態追蹤（「只評估未評估的相片」）
重複 / 近似 / 連拍群組要和整個相片庫比對，新相片可能加入舊群組或改變 Keeper，所以評估仍然整庫計算（數秒）。新增：
- **自動略過**：相片庫、分析結果、會影響評估的設定都沒變時，評估直接略過（`force=true` 可強制）。審核動作（待刪 / 保留）不會讓評估過期。
- **新增 / 移除**：每次評估回報候選新增幾張、移除幾張。
- **待評估提示**：顯示「有 N 張相片在上次評估後完成分析」。
- 狀態存在新的 `app_state` 表（啟動時自動建立；「恢復預設值」不會清掉）。

## 新 API
- `GET /api/workflow/status`：首頁 / 資料庫頁共用的流程狀態、主要分類、審核統計、目前任務。
- `POST /api/jobs/evaluate` body 可選 `{"force": true}`。
- `POST /api/jobs/pipeline` body `{"mode": "full|new_only", "device": "auto|cuda|cpu"}`。

## 前端
- 首頁：4 張統計卡（相片庫 / 待審核 / 待刪 / 已清理）、主要分類長條圖、處理流程。
- 資料庫頁：頂部流程步驟列；評估面板顯示是否最新、上次結果，提供「評估變更」「強制重新評估」與真正的一鍵流水線。
- 新檔：`services/workflow.ts`、`hooks/useWorkflowStatus.ts`、`components/workflow/WorkflowSteps.tsx`（不修改既有 `api.ts` / `types.ts`）。
